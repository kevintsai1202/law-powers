# 公文格式規範參考 (Official Document Format Reference)

本文件依《公文程式條例》、《文書處理手冊》及《政府文書格式參考規範》整理，供 `official-document-drafting` 技能撰擬公文時查核格式細節之用。

## 一、公文種類（依《公文程式條例》第 2 條）

| 種類 | 用途 | 使用情境 |
|---|---|---|
| 令 | 公布法律、發布命令、任免、獎懲官員 | 總統、各級機關首長對所屬 |
| 呈 | 對總統有所呈請或報告 | 對總統用 |
| 咨 | 總統與立法院、監察院公文往復 | 總統與立法院、監察院間 |
| 函 | 機關處理公務最通用之公文 | 上行、平行、下行皆適用 |
| 公告 | 機關就主管業務，向公眾或特定多數人宣布周知事項 | 對外公示 |
| 其他公文 | 書函、開會通知單、公務電話紀錄、簽、報告、聘書、證明書、手令、手諭、箋函、便簽、備忘錄等 | 依用途而定 |

## 二、段落結構

### 函（三段式，得彈性調整）
1. **主旨**：一段完成之事項，全文精要，以最簡明文字扼要敘述，不分項。
2. **說明**：案情來源、經過、有關法規或前案，得分項條列。
3. **辦法**：具體要求或建議，依受文對象性質亦稱「建議」「請求」「擬辦」「核示事項」。

> 案情單純者，得僅用「主旨」一段完成，不必勉強湊成二段或三段。

### 簽（三段式）
1. **主旨**：扼要敘明簽辦之目的與擬處理之意見，不分項。
2. **說明**：案情來源、經過及有關法規。
3. **擬辦**：承辦人簽擬之具體處理意見，供上級判斷、核決或核示。

> 易混淆點：「函」用「辦法」，「簽」用「擬辦」——兩者性質相近但用詞不同，撰寫時務必依公文種類選用正確段落名稱，不可互換。

### 公告（三段式）
1. **主旨**：扼要敘述公告目的與要求，力求簡明。
2. **依據**：公告事項之法令或事實依據。
3. **公告事項**：具體公告內容，得分項條列；得不署機關首長職銜及姓名。

## 三、層級標號與全形半形規則

- 中文字、標點一律使用全形；阿拉伯數字、外文字母及其相關標點一律使用半形。
- 分項條列時，標號依序遞降：一、（一）、1、（1）、甲、(甲)，不得跳號、不得於同一層級混用不同標號系統。

## 四、速別與密等

| 類別 | 選項 | 使用時機 |
|---|---|---|
| 速別 | 最速件、速件、普通件 | 依案情緊急程度標示於文別欄，一般公文可不標示（視為普通件） |
| 密等 | 絕對機密、極機密、機密、密 | 僅涉密案件標示；一般公文不標示密等 |

## 五、發文字號、附件與正副本

- **發文字號**：依機關實際編碼規則，通常為「機關代字＋年度＋類別字＋流水號」，須依實際發文機關規則填列，不得杜撰格式。
- **附件**：正文中應敘明附件名稱及份數；附件不得僅以「詳附件」帶過而未於主旨或說明中交代其性質。
- **正本、副本**：正本為應為受文並負責處理之機關或個人；副本為知會、備查而無須處理之對象；兩者不得遺漏應知會之單位。

## 六、簡式範例

### 函（平行文）範例骨架
```
（機關全銜）函

受文者：○○股份有限公司
發文日期：中華民國○○年○○月○○日
發文字號：○○字第○○○○○○○○○○號
速別：普通件
附件：如文

主旨：檢送本機關○○案處理意見，請　查照。

說明：
一、依　貴公司○○年○○月○○日○○字第○○號函辦理。
二、（案情經過、依據法規）

辦法：請　貴公司於文到後○日內見復。

正本：○○股份有限公司
副本：○○（單位）
```

### 簽範例骨架
```
簽於（單位）

主旨：為○○案，簽請　核示。

說明：
一、（案情來源與經過）
二、（有關法規或前案依據）

擬辦：擬同意（或不同意）○○，簽請　核示。
```
