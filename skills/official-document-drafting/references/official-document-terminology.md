# 公文用語對照表 (Official Document Terminology Reference)

依《文書處理手冊》「公文用語表」整理，供 `official-document-drafting` 技能依行文方向（上行、平行、下行）選用正確用語。**用語必須與行文方向一致**，方向判斷錯誤會導致全篇用語錯誤。

## 一、稱謂語

| 用語 | 使用時機 |
|---|---|
| 大院、大部、大局、大處 | 無隸屬關係之上級機關 |
| 鈞院、鈞部、鈞局、鈞府 | 有隸屬關係之上級機關（對直屬上級機關表尊敬） |
| 貴院、貴部、貴局、貴公司、貴會 | 無隸屬關係之平行機關、下級機關、人民團體或公司 |
| 本院、本部、本局、本公司 | 自稱 |
| 台端 | 機關對人民、屬員之稱謂 |
| 先生、女士、君 | 對無職銜之個人稱謂 |
| 該、職稱 | 於文中重複稱述機關或人員時使用 |

## 二、起首語

| 用語 | 適用範圍 |
|---|---|
| 查、謹查、有關、關於、茲 | 通用 |
| 制定、訂定、修正、廢止 | 公布法律、發布命令用 |

## 三、引敘語

| 用語 | 使用時機 |
|---|---|
| 奉 | 引敘上級機關或首長公文辦理時 |
| 准 | 引敘平行機關或不相隸屬機關公文辦理時 |
| 據 | 引敘下級機關報告或人民陳情辦理時 |
| 依、依照、根據 | 引敘特定法規或辦法辦理時 |

## 四、期望及目的語（依行文方向區分）

| 行文方向 | 常用語 |
|---|---|
| 上行文 | 請鑒核、請核示、請核備、請核准、請鑒察 |
| 平行文 | 請查照、請查照辦理、請惠予同意見復 |
| 下行文 | 希照辦、希查照、希辦理見復、希轉行照辦 |

## 五、准駁語

| 用語 | 使用時機 |
|---|---|
| 應予照准、准予備查 | 上級機關對下級機關陳報事項之核准用語 |
| 未便照准、歉難同意、礙難照准 | 拒絕或不予同意之用語 |

## 六、常見錯誤提醒

- 對**無隸屬關係之上級機關**應使用「大院／大部」而非「鈞院／鈞部」（「鈞」僅用於有隸屬關係者）。
- 對**下級機關或人民**使用「請鑒核」等上行文用語，屬方向錯誤，應改用「希照辦」等下行文用語。
- 「函」與「簽」的段落用詞不同（辦法 vs. 擬辦），不得混用。
