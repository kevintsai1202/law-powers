# 程序時序資料 Schema（`GRAPH_DATA.timeline`）

本文件定義 `data.js` 之 `window.GRAPH_DATA.timeline` 選用欄位的完整結構。此欄位存在且含有效 `deadlines` 與 `events` 陣列時，`index.html` 於頁首顯示「關係圖｜程序時序」分頁切換；欄位不存在時整組隱藏，舊版 `data.js` 完全不受影響（向後相容）。

## ⚠️ 查證鐵律（最高優先）

- `deadlines[].basis`（期限依據條文）與 `routes[].basis` **必須**先經 `legal-research` 技能雙軌檢索查證後填入，**不得憑記憶撰寫條號、期間長度或起算規定**。期間計算規則（`add` 的日／月／年數）亦同。
- 期限之起算日常繫於個案事實（送達日、知悉日、事件日），應以 `params` 開放使用者調整，並於 `hint` 註明預設值之性質（假設值／卷證值）與修正依據。
- 渲染器只做「起算日＋期間」的機械計算，**不計入在途期間、不處理期間末日為假日之順延**；凡有此類限制務必寫入 `warn` 或 `note` 提醒。

## 結構總覽

```js
window.GRAPH_DATA = {
  "nodes": [ /* …既有圖譜資料… */ ],
  "edges": [ /* … */ ],
  "timeline": {                 // ← 選用；不存在時「程序時序」分頁隱藏
    "title":  "程序時序儀表板",   // 選用：分頁大標
    "caseNo": "…法院…字第…號…",  // 選用：副標（法院、案號、案由）
    "warn":   "…",              // 選用：頁首警語（期限計算限制、免責提醒）
    "params": [ … ],            // 必要：可調整之起算日輸入欄
    "deadlines": [ … ],         // 必要：宣告式期限規則
    "events": [ … ],            // 必要：案件事實時間軸事件
    "routes": [ … ],            // 選用：程序路線對照表
    "axisPadDays": 45           // 選用：橫向軸終點留白天數（預設 45）
  }
};
```

## `params[]` — 期限起算參數

| 欄位 | 型別 | 必要 | 說明 |
|---|---|---|---|
| `id` | string | ✅ | 參數識別碼，供 `deadlines[].base` 引用（如 `svcDate`） |
| `label` | string | ✅ | 輸入欄標題（如「判決送達日（上訴起算基準）」） |
| `default` | string | ✅ | 預設日期 `YYYY-MM-DD` |
| `hint` | string | — | 欄位下方提示：預設值性質與修正依據 |

## `deadlines[]` — 宣告式期限規則

| 欄位 | 型別 | 必要 | 說明 |
|---|---|---|---|
| `name` | string | ✅ | 期限名稱（如「上訴期限」）；`routes[].deadline` 以此名稱對照 |
| `base` | string | ✅ | 起算參數 id（必須存在於 `params`） |
| `add` | object | ✅ | 期間：`{"days": n}`、`{"months": n}`、`{"years": n}` 可並用 |
| `basis` | string | ✅ | **經查證**之期限依據條文全銜與要旨 |
| `note` | string | — | 補充提醒（如「※ 在途期間另計」） |
| `offAxis` | boolean | — | `true` 時不繪入橫向等比例軸，改以右側箭頭註記。**適用準則**：該期限與其他事件的時間跨度差距過大（例如 10 年期限對上數月的程序期間），入軸會把其他節點壓縮到不可讀 |

渲染行為：每條 deadline 產生一張倒數卡片（逾期紅／30 日內橙／其餘綠），非 `offAxis` 者同時進入橫向軸與垂直時間軸（以藍色虛線「期限節點」樣式呈現，與當事人陳述明確區隔）。

## `events[]` — 案件事實事件

| 欄位 | 型別 | 必要 | 說明 |
|---|---|---|---|
| `d` | string | ✅ | 西元日期 `YYYY-MM-DD` |
| `roc` | string | — | 民國紀年標註（如 `114-07-08`） |
| `t` | string | ✅ | 事件標題（橫向軸標籤會自動去除全形括號內文字以縮短） |
| `note` | string | — | 補充說明 |
| `cls` | string | — | 事件分類，**攸關法律語意，必須正確標註**：<br>`""`（空）＝判決認定事實；`"alleged"`＝當事人陳述（法院未認定）；`"judgment"`＝判決宣判 |

**分類紀律**：法院於判決理由中未認定真偽之事實（「縱使有之」等語）一律標 `alleged`，不得與認定事實混同——視覺記號本身就是法律語意，共用樣式即是資訊錯誤。

## `routes[]` — 程序路線對照表（選用）

| 欄位 | 型別 | 必要 | 說明 |
|---|---|---|---|
| `name` | string | ✅ | 程序名稱 |
| `basis` | string | — | 期限依據（經查證條文；無法定期限填 `—…`） |
| `deadline` | string | — | 對照之 `deadlines[].name`：填入時狀態欄自動依該期限急迫度顯示標籤 |
| `statusText` / `statusCls` | string | — | 無對照期限時的手動狀態文字與顏色（`r` 紅／`o` 橙／`g` 綠，預設 `o`） |
| `advice` | string | — | 建議欄文字 |

## 渲染器固定行為（不可由資料覆寫）

- 期限急迫度：逾期＝紅、30 日內＝橙、其餘＝綠；天數千分位顯示。
- 橫向軸：時間間距與實際天數等比例；六車道標籤避讓（2D 碰撞檢測）；每節點有引線連至圓點，期限引線依急迫度同色；滑鼠懸停標籤或節點時淡化其他元素凸顯歸屬；今日綠色基準線。
- 日期欄位變更即自動重算（另保留「重新計算」按鈕）。
- 列印（附卷）：自動翻為淺色、隱藏頁首與按鈕、卡片與表格不跨頁截斷。
