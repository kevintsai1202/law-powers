# 法律內容不可變錨點與回歸檢查

法律文字潤稿可能因刪詞、換句或合併段落而改變請求範圍、責任條件或證明程度。改寫前先建立錨點，改寫後逐項比對；不確定時保留原文。

## 不可變錨點

| 類別 | 必須保留的內容 | 常見風險 |
|---|---|---|
| 主體 | 當事人、關係人、代表人、代理人、法院、機關 | 交換原告與被告、債權人與債務人身分 |
| 時間 | 日期、期間、起訖日、送達日、履行期、時效 | 把「翌日起」改成「當日起」或刪除期限起算點 |
| 數值 | 金額、利率、比例、數量、面積、計算方式 | 四捨五入、幣別遺失、利率或計息期間改變 |
| 請求 | 訴之聲明、請求項目、備位聲明、上訴聲明 | 擴張、減縮或合併原本不同的請求 |
| 抗辯 | 否認、時效、同時履行、抵銷、權利失效等抗辯 | 把備位抗辯寫成承認事實 |
| 契約效果 | 權利義務主體、條件、例外、期限、解除／終止、違約效果 | 改變責任成立要件或適用範圍 |
| 定義與引用 | 定義詞、條號、附件、交互引用、證據編號 | 同義詞替換造成定義失配 |
| 法源 | 法規全名、條項款目、法院、年度、字號、裁判類別 | 簡化、誤植或生成不存在的字號 |
| 引文 | 法條原文、裁判原文、契約原文、證人陳述 | 為求流暢而改寫直接引文 |
| 證明程度 | 可能、推認、尚難認定、顯有疑義、足認等限定 | 刪除限定後把推論變成確定事實 |

## 文件類型檢查

### 書狀

- 訴訟聲明、上訴聲明及聲請事項逐字比對。
- 當事人稱謂與程序地位前後一致。
- 原因事實與法律理由沒有因重排而互相混淆。
- 備位主張仍清楚標示，不得改成自認或無條件主張。
- 證據編號、待證事實及附件引用一致。

### 契約

- 定義詞大小寫、全稱與簡稱一致。
- 「應」、「得」、「不得」、「除非」、「但」等規範語氣不變。
- 條件、例外、期限、通知方式及救濟條款完整保留。
- 違約金、損害賠償、責任限制、解除與終止效果沒有互換。
- 條號與交互引用在段落移動後仍正確。

### 法律意見與客戶說明

- 已查證事實、客戶陳述、對造主張與法律推論分開標示。
- 風險程度與不確定性不因去 AI 味而被放大或弱化。
- 法源引用仍能回溯到檢索結果。
- 未新增勝訴保證或無來源的實務見解。

## 回歸檢查方法

1. 從原文擷取所有姓名、日期、數值、編號及引用，建立逐字清單。
2. 從修訂稿再次擷取同類內容，確認沒有缺漏、增生或變更。
3. 逐句檢查「應／得／不得」、「且／或」、「除非／但書」及否定詞。
4. 比對每一項請求、抗辯、條件與例外的主體及法律效果。
5. 對直接引文做逐字比對；若需白話說明，另起一句，不改引文本身。
6. 若無法確認某項替換是否影響法律效果，恢復原文並列入待確認事項。
7. 分開檢查「引用識別資訊」與「引用內容」：保留判決字號不代表已驗證該判決支持原文論點；沒有裁判原文或檢索結果時，只能標示為當事人援引或尚待查證。

## 校訂完成聲明

只有全部檢查通過時，才可在摘要中寫：

> 未新增法律主張或法源，未調整日期、金額、請求、抗辯及權利義務。

若有任何實質調整，應逐項列出，不能使用上述聲明。
