# 台灣法律專業術語校訂表

本表用於把一般中文、中國大陸法律用語或翻譯腔轉為中華民國（台灣）法律實務常用語。「待校訂用語」欄可保留簡體字，以忠實呈現錯誤或待訂正資料；其餘說明均使用繁體中文。表中非台灣用語僅供辨識其法律制度來源，不代表台灣法律採用該用語。先判斷文件類型與法律關係，再選詞；表格不是無條件字串替換規則。

## 一般法律用語

| 待校訂用語 | 台灣法律用語 | 使用注意事項 |
|---|---|---|
| 合同 | 契約／合約 | 法律分析及正式條款通常優先用「契約」；既有文件定義為「合約」時維持一致。 |
| 解除合同 | 解除契約 | 若僅向將來失效，可能應使用「終止契約」，須依法律效果判斷。 |
| 违约责任 | 違約責任／債務不履行責任 | 依請求權基礎選詞，不要一律替換成損害賠償。 |
| 索赔 | 請求損害賠償／請求給付 | 依實際請求內容選擇，不使用口語「索賠」。 |
| 赔偿金 | 損害賠償／損害賠償金額 | 若是保險給付、補償或其他法定給付，應保留其法律性質。 |
| 诉讼时效 | 消滅時效 | 刑事追訴權時效、行政法期間等另依制度處理。 |
| 撤诉 | 撤回起訴／撤回上訴 | 依程序階段選詞。 |
| 一审／二审 | 第一審／第二審 | 必要時改為原審、上訴審，但不得混淆審級。 |
| 律师 | 律師 | 若原文指外國律師資格，保留法域資訊。 |
| 代理律师 | 訴訟代理人／委任律師 | 依程序身分選詞。 |
| 诉求 | 請求／聲明 | 書狀中通常用「訴之聲明」或「請求」。 |
| 判令 | 判命／判決主文記載「被告應……」 | 當事人書狀可寫「請求法院判命」；轉述判決時依主文原文。 |
| 法院支持 | 法院認為有理由／准許／判決勝訴 | 依裁判結果精確表達。 |
| 举证责任 | 舉證責任 | 不得因潤稿改變舉證責任分配。 |
| 质证 | 證據調查／就證據表示意見 | 依程序行為選詞，台灣法沒有完全等同的固定用語。 |
| 管辖权异议 | 管轄權抗辯／聲請移送管轄 | 依當事人實際聲請內容選詞。 |
| 工伤 | 職業災害 | 若引述外國法律制度，保留原制度名稱並說明。 |

## 必須依情境判斷的用語

### 罰款

- 契約約定一方違約時給付：通常為「違約金」。
- 行政機關依行政法規裁處：使用「罰鍰」。
- 刑事法院科處財產刑：使用「罰金」。
- 公司或團體內部管理措施：可能是「懲處」、「扣款」或其他性質，不得自行定性。

### 起訴書

- 民事或行政事件由當事人向法院提起訴訟：使用「起訴狀」。
- 刑事案件由檢察官提起公訴的文書：可使用「起訴書」。
- 刑事自訴人提出的文書：使用「刑事自訴狀」。

### 辯護詞

- 民事被告回應原告主張：使用「答辯狀」或「答辯意旨」。
- 刑事辯護人提出法律與事實意見：使用「辯護意旨」或「辯護意旨狀」。
- 行政訴訟被告機關回應：依文件功能使用「答辯狀」。

### 法定代表人

- 公司依公司法登記之代表者：通常使用「代表人」。
- 未成年人、受監護宣告人等由法律規定代理：使用「法定代理人」。
- 不得只因原文寫「法定代表人」就一律替換，應先確認主體與法律身分。

## 書狀與程序用語

| 功能 | 建議用語 |
|---|---|
| 原告提出具體裁判要求 | 訴之聲明／請求法院判命 |
| 被告否認請求 | 原告之訴駁回／原告之請求無理由 |
| 提出替代性主張 | 備位主張／如法院認為……則…… |
| 說明證據目的 | 待證事實／證明事項 |
| 引用附件 | 原證一、被證一、附件一（依程序與既有編號） |
| 請法院調取資料 | 聲請調查證據／聲請命第三人提出文書 |
| 對判決不服 | 提起上訴／上訴聲明 |
| 放棄或縮減請求 | 撤回起訴／減縮應受判決事項之聲明 |

## 不得在地化的內容

- 外國法院、行政機關、法律名稱及正式職稱。
- 直接引文、裁判原文、契約原文及證據原文中的用語。
- 當事人自行定義的專有名詞，除非修約範圍明確包含定義詞調整。
- 可能影響法域判斷的制度名稱。

遇到上述內容，可在引文外另加台灣讀者可理解的說明，但不得改寫來源本身。
